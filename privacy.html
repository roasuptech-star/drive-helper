Privacy Policy

Drive Helper is a private internal tool used only by its owner with the owner’s own Google account.

Data the app accesses

With the owner’s permission the app uses the Google Drive API to read document templates, copy them, create folders, rename the copies and change link sharing of the copies it creates.

How the data is used

Only to perform these actions at the owner’s request. The app does not sell, transfer or disclose Google user data to third parties and does not use it for advertising.

Storage

The app keeps only the authorization token needed to act on the owner’s behalf, stored as a private server setting. Document contents are not stored outside Google Drive.

Revoking access

Access can be revoked at any time in the Google Account settings (Security → Third-party apps).

Google API Services User Data Policy

The app’s use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
